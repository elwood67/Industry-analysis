# Industry Trend Analysis - User Guide

## What This Tool Does
This tool helps you spot which industries are showing strong bullish or bearish trends in the market. It analyzes stock data over time and shows you which industries are gaining momentum in either direction.

## Getting Started

### Main Controls (Left Sidebar)

#### 1. Market Cap Categories
- Choose from Mega Cap (biggest companies) down to Nano Cap (smallest companies)
- **Tip**: You can select multiple categories at once
- **Example**: Selecting both "Large Cap" and "Mega Cap" will show trends for all the biggest companies

#### 2. Score Type Selection
- **Bullish**: Shows industries gaining positive momentum
- **Bearish**: Shows industries gaining negative momentum

#### 3. Analysis Window Size (3-10)
- Smaller numbers (3-5): Better for spotting quick changes
- Larger numbers (7-10): Better for longer-term trends
- **Tip**: Start with 5 and adjust based on what you're looking for

#### 4. Trend Shift Threshold (1.0-3.0)
- Lower numbers: More sensitive to small changes
- Higher numbers: Only shows major shifts
- **Tip**: Start at 2.0 - lower it if you want to catch more subtle changes, raise it if you want only the strongest trends

#### 5. Number of Industries to Show (5-20)
- Controls how many industries appear in your results
- **Tip**: Start with 10 to get a good overview

## Understanding the Visualizations

### 1. Main Trend Chart
- Shows industries with the strongest trends
- Green bars = positive changes
- Red bars = negative changes
- Numbers on the bars show:
  - How much the score changed
  - Current score for that industry
- **Tip**: Longer bars mean stronger trends

### 2. Industry Timeline Chart
- Shows how a specific industry's score has changed over time
- Blue line: Daily scores
- Dotted line: Trend line (helps spot overall direction)
- **Tip**: Use this to verify if a trend looks consistent or volatile

### 3. Trend Statistics Table
- Detailed numbers for each industry shown
- Sortable by clicking column headers
- Download button available for saving results

## Quick Tips for Best Results

### For Quick Market Changes
- Set Window Size to 3-4
- Set Threshold to 1.5-2.0
- Good for day-to-day trading decisions

### For Longer Term Trends
- Set Window Size to 7-10
- Set Threshold to 2.0-2.5
- Better for weekly or monthly analysis

### For Specific Stock Types
- **Big, Stable Companies**: Select Mega and Large Cap
- **Growth Companies**: Try Mid and Small Cap
- **Speculative Stocks**: Include Micro and Nano Cap

## Common Questions

### Why are my results empty?
- Make sure you've selected at least one Market Cap category
- Try lowering the Trend Shift Threshold
- Increase the Number of Industries to Show

### Why did the trends change dramatically?
- Small Window Size can show more volatile changes
- Check if you changed Market Cap selections
- Market conditions might have shifted significantly

### Best Settings for Beginners
1. Select "Large Cap" and "Mega Cap"
2. Set Window Size to 5
3. Set Threshold to 2.0
4. Show top 10 industries
5. Start with Bullish score type

## Need More Help?
- Try different combinations of settings
- Compare Bullish vs Bearish views
- Look at both charts and statistics together for better insights

Remember: This tool is meant to help spot trends - always do additional research before making any investment decisions!
